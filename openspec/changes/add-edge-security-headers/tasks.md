Expected and correct; recorded so it is not debugged cold. See 3.5

- [x] 0.4 Confirm bloomctl never inspects `Content-Type` — no references in `bloomcli/src`; the header cannot affect non-browser clients, which do not sniff
- [x] 0.5 Measure Supabase Studio and MinIO console bundles against the image pins prod runs — Studio `2026.03.30-sha-12a43e5`: 92/92 assets correctly typed; MinIO `RELEASE.2025-01-20T14-49-07Z`: 3/3 correctly typed; both do create `<iframe>` elements, but none whose `src` is a URL we serve: MinIO's object-preview frame is unreachable in this build (it renders only for object types its own classifier cannot produce) and Studio's are `about:blank` or a third-party CDN, so `X-Frame-Options: DENY` reaches none of them. Both safe under all five headers measured, which is what makes site-level coverage viable. `Cross-Origin-Opener-Policy` and `Cross-Origin-Resource-Policy` were both added afterwards and neither was re-measured against the consoles. `same-origin-allow-popups` was chosen precisely so COOP cannot affect them, since it restricts being opened rather than opening; CORP likewise governs who may load a console's resources, not what a console may load. So the measurement covers five of the seven headers, and the two later ones are argued rather than measured

### Regression guards

- [x] 2.8 `tests/unit/test_caddy_security_headers.py` — pins site-level placement by brace-matched depth and asserts values verbatim, so relocating the block inside a `handle` or weakening a value (`SAMEORIGIN` for `DENY`, `'unsafe-inline'` creeping into the CSP) fails CI. Every override shape Caddy allows is recognised — the `header { ... }` block with or without a matcher, the single-line `header <Field> <value>` / `header -<Field>` including wildcard deletions such as `-X-Frame-*` and `-*`, and a `header_down` inside a `reverse_proxy` body — since each downgrades the policy for one host alone. The host list is derived from the site block, so renaming a matcher cannot make the guard skip a host. Verified by mutation against a live Caddy: every such shape fails the check, while harmless edits (trailing comments, backtick quoting, an unrelated added header) still pass
- [x] 2.9 `tests/integration/test_api_endpoints.py` — asserts each header reaches the client with its exact value and no *differing* duplicate, across every handler class and each upstream Kong fans out to (GoTrue, PostgREST, storage-api), plus a guard that HSTS is still absent. Divergence rather than a count for the headers that resolve last-wins: a byte-identical duplicate changes nothing a browser observes, a differing one does. `Cross-Origin-Opener-Policy` and `Cross-Origin-Resource-Policy` are the exception — any duplicate voids them, since repeated field lines join with a comma that parses as neither a legal value nor a single structured-field item, so both are held to exactly one occurrence
