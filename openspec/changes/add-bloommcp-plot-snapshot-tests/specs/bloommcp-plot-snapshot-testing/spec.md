## ADDED Requirements

### Requirement: Baseline Coverage For The 5 Plotting Tools

`bloommcp/tests/fixtures/plot_baselines/` SHALL contain one committed baseline PNG for
each of the 5 `sections/sleap_roots/analysis/` plotting tools (`plot_trait_histograms`,
`plot_trait_boxplots`, `plot_correlation_matrix`, `plot_heritability_bar`,
`plot_variance_decomposition`), generated by `bloommcp/scripts/gen_plot_snapshots_golden.py`
against the `turface_19_final_data.csv` fixture via each tool's real MCP entrypoint (not
its delegate directly), plus a `MANIFEST.json` recording the rendering environment's
provenance (matplotlib/Pillow/sleap-roots-analyze versions, platform).

#### Scenario: Every dedicated plotting tool has a baseline

- **WHEN** a developer inspects `bloommcp/tests/fixtures/plot_baselines/`
- **THEN** it contains `histograms_turface_19_baseline.png`,
  `boxplots_turface_19_baseline.png`, `correlation_matrix_turface_19_baseline.png`,
  `heritability_turface_19_baseline.png`, `variance_decomposition_turface_19_baseline.png`,
  and `MANIFEST.json`

#### Scenario: Baselines are regenerable, not hand-authored

- **WHEN** `uv run --extra test python scripts/gen_plot_snapshots_golden.py` runs
- **THEN** it overwrites every baseline PNG and `MANIFEST.json` by calling the 5 tool
  functions directly against a temp `TRAITS_DIR`/`PLOTS_DIR`, with no live Supabase stack
  or network access required

### Requirement: Pixel-Diff Regression Coverage With A Calibrated Tolerance

`bloommcp/tests/tools/test_viz_snapshot.py` SHALL compare each of the 5 plotting tools'
real rendered output against its baseline PNG using
`matplotlib.testing.compare.compare_images` at a documented, empirically-derived RMS
tolerance constant, and SHALL include a test proving that tolerance still catches a
deliberately regressed render.

#### Scenario: A correct render passes

- **WHEN** `test_plot_matches_baseline_within_tolerance` runs each of the 5 tools against
  the `turface_19` fixture through the `viz_env` fixture
- **THEN** `compare_images(baseline, actual, tol=_TOL)` returns `None` for all 5

#### Scenario: The tolerance is not a rubber stamp

- **WHEN** `test_tolerance_catches_a_real_regression` runs
- **THEN** a real baseline PNG uniformly dimmed by 10% via `PIL.ImageEnhance.Brightness`
  is compared against the unmodified baseline at the same `_TOL`, and
  `compare_images` returns a non-`None` result (the regression is caught)

#### Scenario: A missing baseline fails with an actionable message

- **WHEN** a baseline PNG referenced by `test_plot_matches_baseline_within_tolerance` does
  not exist
- **THEN** the test fails with a message naming the missing path and the command to
  regenerate it (`scripts/gen_plot_snapshots_golden.py`), not a bare `FileNotFoundError`

### Requirement: Runs Unmarked In Per-PR CI

Every test in `test_viz_snapshot.py` MUST run unmarked (no `integration`, `live_smoke`, or
`live_smoke_slow` marker) so it executes inside the existing `python-audit` CI job's
default `pytest tests/ -m "not integration and not live_smoke"` invocation on every PR,
with no live dev stack required.

#### Scenario: python-audit's default invocation includes the snapshot tests

- **WHEN** the `python-audit` CI job's pytest invocation collects `bloommcp/tests/`
- **THEN** every test in `test_viz_snapshot.py` is collected and executed (not excluded by
  the `-m "not integration and not live_smoke"` filter)
