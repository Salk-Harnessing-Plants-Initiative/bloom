# Tasks

TDD throughout: write/adjust the test first (red), then make it pass (green). Every
intermediate commit MUST leave CI green — the two gates that define green are the full
bloommcp suite (`uv run --frozen --extra test pytest`, which fails at *collection* if any test
file imports a deleted module at top level) and the wheel-import gate (`import bloom_mcp.server`,
which fails if any registered module has a dangling import). Commit numbers (C1–C11) follow the
reviewed commit plan; do **not** squash — Benfica reviews commit-by-commit.

"No functionality lost" is a first-class gate: every deleted symbol is proven present upstream
before its vendored copy is removed (C2/C10).
